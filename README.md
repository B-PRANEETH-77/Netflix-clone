# Netflix Clone

A Netflix-inspired website built using **HTML and CSS**, recreating the look and feel of the Netflix landing page with a responsive layout and visually appealing design.

## Technologies Used
- HTML5
- CSS3

## Features
- Netflix-inspired user interface
- Responsive layout
- Styled navigation and content sections
- Modern design using CSS

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the Netflix-inspired interface.
